# 介绍

在这一部分中，我们将介绍两个重要主题，为你在乐鑫设备上使用 Rust 打下基础：

1. **[硬件概览](./hardware-overview.md)**：了解乐鑫生态系统，包括不同的 SoC 系列、架构和开发板。这些知识有助于你为项目选择合适的芯片，并了解即将编程控制的底层硬件。

2. **[辅助 crate 概览](./ancillary-crates.md)**：探索 crate 生态系统。这些 crate 提供了从内存分配到无线通信的各种基础组件。

了解硬件能力和软件生态系统后，你就可以继续学习[入门](../getting-started/index.md)章节中的实践内容，配置开发环境，并创建你的第一个应用程序。

让我们先了解将要使用的硬件。
