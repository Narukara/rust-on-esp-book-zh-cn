# 继续探索

我们希望本书已帮助你做好准备，使用乐鑫芯片和 Rust 构建实际应用。这里介绍的只是入门内容，本书之外还有许多值得探索的主题。如果还没有阅读[补充资源][the additional resources]，请务必看一看。

我们期待看到你的作品。欢迎将它加入 [awesome-esp-rust] 列表，也可以从这个列表中寻找灵感。

如果你希望直接为 `esp-hal` 或辅助 crate 做贡献，请参阅[开发者贡献文档][our developer contribution documentation]。
